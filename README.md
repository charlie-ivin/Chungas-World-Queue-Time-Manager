This is a Queue Time Manager for Chungas World Game Server (https://www.chungasworld.co.uk) for there Coasters Park site managering there queue times, attractions, private events and the operating hours.

The Coasters Park / Chungas World Admin Staff can edit the park map and queue time via the admin page and login with there login github user key.
